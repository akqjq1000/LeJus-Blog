LeJus Blog를 GitHub Pages로 시작하는 첫 포스트입니다.

이 블로그은 cybersecurity, network monitoring, packet capture, low-level security research를 다루며, 모든 지식을 직접 실행(empirical experimentation)을 통해 검증하는 방향을 따릅니다.

아래는 이 블로그의 기본 구조입니다.

- `_posts/` — 포스트 파일 (Markdown)
- `_config.yml` — Jekyll 설정
- `index.md` — 블로그 홈 (포스트 목록)

새 포스트를 작성하면 `main`에 push하면 GitHub Pages가 자동으로 빌러서 게시합니다.
